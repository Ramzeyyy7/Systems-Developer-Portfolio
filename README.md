# Systems Developer & Web Designer Portfolio

A fully responsive, semantic personal portfolio website built with Bootstrap 5 CSS and custom styling, featuring a hero section, an about me card grid, featured project cards, and an accessible contact form.

## 🚀 Live Demo
* [View Live Site](https://your-live-url-here.netlify.app)

---

## 🛠️ Implemented Sections & Features
1. **Hero Section:** Full-bleed background image with a dark overlay, center-aligned typography, and a sticky top navigation bar with active state underlines.
2. **About Me Card:** A clean two-column layout containing a profile image, contact details, custom Bootstrap skill badges, and a professional bio.
3. **Projects Grid:** A responsive 3-column grid showcasing 6 projects (including Tesla, Netflix, and YouTube clones) with banner images, subtitles, live links, and code buttons.
4. **Contact Section:** Centered heading with highlight labels, social media icon row (Instagram, GitHub, LinkedIn), and an accessible contact form with HTML validation.
5. **Footer:** Dark branding bar with centered developer attribution.
6. **Bonus Implemented:** Auto Dark Mode utilizing `prefers-color-scheme` and CSS custom variables.

---

## 💻 Tech Stack & Standards
* **HTML5** (Semantic landmarks: `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`)
* **Bootstrap 5 (CDN)** for layout grids and utility classes
* **Bootstrap Icons** for vector icons
* **Custom CSS** (`styles.css`) with CSS variables and media queries
* **Zero JavaScript** (Pure native HTML/CSS implementation)
